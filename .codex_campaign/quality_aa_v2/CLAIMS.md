# Revendications

## Supported

Sous les fixtures et gates prospectifs `FSSR-QUALITY-AA-v2`, `full_island_x2` est un backend AA synthétiquement qualifié et compatible avec le profil natif préenregistré.

## Not supported

Aucune conclusion n'est permise sur une architecture d'ampli, une capture matérielle, une fidélité physique ou l'état de l'art global.
